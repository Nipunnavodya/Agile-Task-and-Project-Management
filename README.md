# 1. Agile Task & Project Management (Trello, Jira, ClickUp)

This folder contains project management artifacts demonstrating Agile, Scrum, and Kanban workflows across industry-standard project tracking platforms.

## Projects & Deliverables

### Agile Kanban Board (Trello)
- **Tool:** Trello
- **Project Scope:** E-commerce project එකක් සඳහා To Do, In Progress, QA Testing, සහ Done ඇතුළත් Kanban Board එකක් සෑදීම.
- **Artifacts:** Kanban board structure, workflow automation rules, and task cards with acceptance criteria.

### Scrum Sprint & Burndown Metrics (Jira Software)
- **Tool:** Jira Software
- **Project Scope:** Sprint Backlog, Epics, User Stories, Story Points (Fibonacci) සකස් කර Burndown Charts පරීක්ෂා කිරීම.
- **Artifacts:** Sprint reports, backlog prioritization, story point allocation, and burndown chart metrics.

### Interactive Project Timeline (ClickUp / GanttProject)
- **Tool:** ClickUp / GanttProject
- **Project Scope:** Software Release එකකට Work Breakdown Structure (WBS) සහ Critical Path ඇතුළත් Interactive Gantt Chart එකක් සැකසීම.
- **Artifacts:** Interactive Gantt chart exports, WBS hierarchy, dependencies, and critical path milestones.
