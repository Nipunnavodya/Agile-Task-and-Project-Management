## 📌 Domain Overview
This repository contains end-to-end Agile project management artifacts demonstrating proficiency in sprint execution, story point estimation, release timeline planning, and workflow automation.

---

## 🚀 Projects & Deliverables

### 1. Agile Kanban Board (Trello)
* **Tool:** Trello
* **Project Scope:** Configured a comprehensive workflow board for an E-commerce platform to streamline continuous feature delivery.
* **Key Implementation:**
  * Configured stages: `To Do` ➔ `In Progress` ➔ `QA Testing` ➔ `Done`.
  * Set up task categorization, card checklist automation, and priority labeling (`P0-Blocker`, `P1-High`).

### 2. Scrum Sprint & Burndown Metrics (Jira Software)
* **Tool:** Jira Software
* **Project Scope:** Planned, estimated, and executed structured 2-week development sprints.
* **Key Implementation:**
  * Structured Product Backlog with clear Epics, User Stories, and Acceptance Criteria.
  * Estimated work effort using the Fibonacci Story Points scale (1, 2, 3, 5, 8, 13).
  * Analyzed Sprint Velocity, Commitment vs. Done metrics, and Burndown Charts to eliminate bottlenecks.

### 3. Interactive Project Timeline (ClickUp / GanttProject)
* **Tool:** ClickUp / GanttProject
* **Project Scope:** Built a release management roadmap for an enterprise software deployment.
* **Key Implementation:**
  * Modeled a complete Work Breakdown Structure (WBS) with task dependencies (Finish-to-Start).
  * Calculated the Critical Path Method (CPM) to safeguard go-live milestones against schedule slippage.
